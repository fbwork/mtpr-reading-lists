# MTPR: Modified Themed PageRank

Implementation and evaluation code for **"Topic-Sensitive PageRank with
Graph Centrality Weighting for Scientific Reading List Recommendation"**
(Bagherpour & Afsharchi).

MTPR is a family of 19 topic-sensitive PageRank variants for automatically
generating reading lists for researchers entering a new scientific field.
It extends Jardine's (2014) Themed PageRank with four graph centrality
measures (degree, closeness, betweenness, Katz) and author-credibility
signals, applied to both the bias (personalisation) and transition
components of the model.

This is research code released for reproducibility of the paper's
results; it is not a packaged library.

## Repository structure

```
components/    Core library: LDA topic modelling, PageRank variants,
                centrality computation, ATR, author scoring, frozen
                Theta artifact handling
models/        Database schema (Paper, Author, PaperCitation, etc.)
utils/         Shared helpers (task orchestration, flags, cleaning)

main.py                          CLI entry point
run_all_pageranks.py             Compute all 19 PageRank variants
run_single_method.py             Compute one PageRank variant
run_eval_all_fast.py             Run the full evaluation pipeline
run_tchpr.py                     Topic-and-Centrality-weighted HITS/PageRank runner

build_theta_artifact.py                  Materialise the frozen Theta (document-topic) artifact
theta_frozen_reproducibility_check.py    Verify bitwise reproducibility of a frozen artifact
theta_multipass_diagnostic.py            Multi-pass averaging diagnostic for Theta
theta_regeneration_diagnosis.py          Diagnose regeneration variance
theta_stability_check.py / _check2.py    Additional Theta stability checks
reset_theta_dependent_caches.py          Invalidate caches after a Theta artifact rebuild

csc_evaluation.py                Citation Substitution Coefficient (CSC) evaluation on AAN
csc_with_baselines.py            CSC evaluation including BM25/Doc2Vec baselines
wilcoxon_significance_check.py   Wilcoxon signed-rank significance test (AAN)
jardine_replication_check.py     Sanity check against Jardine's (2014) reported TPR behaviour

acl_rlg_pilot.py                          Initial (non-temporal) ACL-rlg evaluation
acl_rlg_centrality_worker.py              Centrality computation on the full ACL-rlg citation graph
acl_rlg_centrality_worker_temporal.py     Per-tutorial-year truncated-graph centrality computation
acl_rlg_final_eval.py                     Full (non-temporal) ACL-rlg evaluation
acl_rlg_final_eval_temporal.py            Temporally-corrected ACL-rlg evaluation (used in the paper)
acl_rlg_paired_significance.py            Paired Wilcoxon test, bw_modified_bias vs. BM25, on ACL-rlg
```

## Provenance records

`results/theta_artifact/` contains the metadata of the frozen `Theta`
artifacts (AAN and ACL-rlg: seeds, document order, library versions,
artifact and corpus-order SHA-256) and `provenance_aan_T200.json`, the full
SHA-256 hashes of the AAN LDA model file and dictionary (the paper's
Supplementary Material lists their 16-character prefixes). The `Theta`
matrices themselves are regenerated by `build_theta_artifact.py`.

## Reproducibility protocol

All downstream computations (bias, transition, centrality-subgraph
membership, author scores, query construction) read from a single,
frozen, versioned document--topic matrix `Theta` (`components/theta_artifact.py`,
`build_theta_artifact.py`), rather than calling Gensim's
`get_document_topics()` on demand, which we found to be non-deterministic
across repeated calls on an unchanged trained model. This protocol,
its extraction procedure, and its cross-process verification are
described in the paper's Methodology and Supplementary Material.

## Setup

1. Python 3.10, PostgreSQL 13 (see `docker-compose.yml` for a local
   Postgres instance).
2. `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in your own database
   credentials.
4. Populate the database from the AAN corpus (Radev et al., 2013) and,
   for the ACL-rlg experiments, obtain the ACL-rlg dataset
   (Aubert-Beduchaud et al., 2025) separately from its own repository.

Data files (the AAN/ACL-rlg corpora, trained models, frozen `Theta`
artifacts, and cached centrality/PageRank results) are not included in
this repository; they are regenerated by the scripts above from the
source corpora.
